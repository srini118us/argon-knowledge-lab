## 1. Purpose

Every data element Northwind processes carries one of three classes. Controls in the security policy are tied to these classes, so classification is the first step in any review.

## 2. Classes

**DC-2.1 C1 Internal.** Operational data that identifies no person and no payment instrument. Disclosure would be inconvenient but not harmful.

**DC-2.2 C2 Confidential.** Personal data: any data that identifies or locates a natural person, including customers and drivers.

**DC-2.3 C3 Restricted.** Payment card data and bank account data.

## 3. Classification of common data elements

| Data element | Description | Class |
|---|---|---|
| Shipment ID | Internal identifier of a shipment | C1 |
| Route plan | Planned stops and sequence for a vehicle | C1 |
| Vehicle telemetry | Speed, fuel, engine and temperature readings from vehicles | C1 |
| Customer email address | Email address of a shipper or recipient | C2 |
| Customer phone number | Phone number of a shipper or recipient | C2 |
| Delivery address | Street address of a recipient | C2 |
| Driver location | Live or historical GPS position of a named driver | C2 |
| Card number (PAN) | Primary account number of a payment card | C3 |

**DC-3.1** A data set or integration takes the highest class of any element it contains.

## 4. Notes

Vehicle telemetry is C1 because it is keyed by vehicle, not by driver. If telemetry is joined with a driver roster it becomes driver location and is C2. Aggregated statistics that cannot be traced back to a person are C1.
